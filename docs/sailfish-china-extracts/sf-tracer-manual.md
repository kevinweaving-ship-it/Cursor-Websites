# 小橙盒使用手册 ​

## 设备外观 ​

[img:设备外观示意]

 |  | 指示灯 | 颜色 | 说明
 | GPS灯(左) | 蓝色 | GPS 定位状态
 | 电源灯(中) | 红色 | 充电状态
 | 信号灯(右) | 橙色 | 网络连接状态

## 1. 设备开关机 ​

### 手动开机 ​

短按 SOS 按键 即可开机。

### 手动关机 ​

长按 SOS 按键 3 秒 关机。

注意

灯闪后请马上松手

### 远程开关机 ​

使用 旗鱼后台管理系统，可以对设备进行远程开关机。

注意

手动关机后，远程开关机功能将不可用

## 2. 指示灯说明 ​

### 信号灯（橙色） ​

 |  | 状态 | 含义
 | 常亮 | 已连接服务器
 | 快闪 | 服务器连接断开

### 电源灯（红色） ​

 |  | 状态 | 含义
 | 常亮 | 充电中
 | 熄灭 | 未充电或已充满

### GPS 灯（蓝色） ​

 |  | 状态 | 含义
 | 常亮 | 定位成功
 | 闪烁 | 定位失败

### 组合指示灯状态 ​

 |  | 组合状态 | 含义
 | 信号灯 + GPS 灯慢闪（约1秒1次） | SOS 信号发送中
 | 信号灯 + GPS 灯快闪（约1秒2次） | 关机中
 | 信号灯常亮 + GPS 灯熄灭 + 电源灯熄灭 | 休眠状态

## 3. SOS 功能 ​

### 发送 SOS ​

快按 SOS 按键 3 次，开始发送 SOS 信息。

### 解除警报 ​

再次快按 SOS 按键 3 次，解除警报。
