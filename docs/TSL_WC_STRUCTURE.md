## Season and teams

| Q | Answer |
| --- | --- |
| Registration | **Per event.** 3 training events + one Regional final (noted 16/17 Oct; Event URL / NOR are 17–18 Oct). |
| Same team all season? | **No.** Teams may differ for each event. |
| Sailor can change teams? | **Yes.** Clubs may field more than one team (e.g. Stellenbosch) so sailors can be shuffled. Some sailors belong to more than one club (e.g. ZVYC and Hermanus). Formal change conditions still open. |
| Roster size | **6** for 3×3 (plus manager as reserve in the NOR). **4** if 2×2. Oppies are single-handed. |
| Female | **50% for the entire program** (not a per-team hard rule on one event). |
| Race / age | **50% PDI / 35% under 18 for the entire program.** |

NOR team list for this final: EDEN, OVERBERG, ZVYC, RCYC Training Centre, Stellenbosch University Sailing Club, UCT Sailing Club, IZIVUNGU, MAC.

## Format (WC)

| Q | Answer |
| --- | --- |
| 3v3 this district all year? | **Yes.** |
| Any 2v2 in this series? | **No.** |
| Scoring | **Positional race** (1+2+3…). Team race score = sum of three boat places. **Lowest team score wins that race** (RRS D3.4). Overall round-robin order is **race wins** (D4.3), not accumulated points. Live gold table: `docs/TSL_WC_SCORING_D4.md`. |
| Tie-break | RRS D4.4. Officials’ 15-race sheet left Eden and RCYC B as **unresolved joint second**; do not claim D4.4 established that joint place. |
| Competition format | Asked as round-robin + final. **Not answered here.** NOR: 8 teams → 28 round-robin races; if unfinished, two flights then knock-out for winners and runners-up. |

Do not use Appendix A. Do not store W/L unless a later NOR says so. Race cells hold the team’s place-total for that race.

## Event URL consequences

- One Event URL, one TSL fleet, one row per **team**.
- Seed / enter the eight NOR teams when ready. Roster up to 6 + manager; 3 boats on the water.
- Admin enters each race as a **place total** (lower better).
- Injury sub only, RO approval, same roster, sailor may return.
- SAS TSL 410s rotate; no privately owned TSL boats on this sheet.
- Program 50% female / 50% PDI / 35% U18 is tracked for SAS reporting, not as a per-race column unless the booklet says so.
